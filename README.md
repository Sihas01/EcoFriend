## 📌 Overview
EcoFriend is a web application designed to promote responsible electronic waste management. It provides a platform for users to efficiently dispose of e-waste, find recycling centers, and learn about sustainable practices.

## 🚀 Features
- 📑 **E-Waste Disposal Guidelines** - Educate users on proper e-waste disposal methods.
- 🎨 **Smooth Animations** - Integrated **Anime.js** for engaging UI/UX animations.
- 🔐 **User Authentication** - Users can create accounts and log in to access platform features.
- ♻️ **E-Waste Donation** - Users can donate usable and unusable e-waste.
- 🛒 **E-Shop** - Usable e-waste is added to an online shop at reasonable prices.
- 🏗️ **Recycled Products Marketplace** - Unusable e-waste is repurposed into new products and sold in a separate section.
- 💰 **Sell E-Waste** - Users can list both usable and unusable e-waste for sale.

## 🛠️ Tech Stack
- **Backend**: PHP
- **Database**: MySQL
- **Frontend**: HTML, CSS, JavaScript
- **Animations**: Anime.js

## 🔧 Installation & Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/Sihas01/EcoFriend.git
   ```
2. Navigate to the project directory:
   ```bash
   cd EcoFriend
   ```
3. Set up the database:
   - Import the provided SQL file (`database.sql`) into MySQL.
   - Configure database credentials in `config.php`.
4. Start a local server (using XAMPP, WAMP, or LAMP):
   - Place the project inside the `htdocs` (for XAMPP) or appropriate directory.
   - Start Apache and MySQL services.
5. Open the application in a browser:
   ```
   http://localhost/EcoFriend
   ```
